О Linux Foundation:<br/>
Linux Foundation (LF) — некоммерческая организация, созданная в 2000 году для поддержки разработки Linux и проектов программного обеспечения с открытым исходным кодом.<br/>
 <br/>
Среди значимых проектов Linux Foundation:<br/>
LF AI & Data Foundation - это проект Linux Foundation, который поддерживает инновации с открытым исходным кодом в области искусственного интеллекта, машинного обучения, глубокого обучения и проектов с открытым исходным кодом данных. <br/>
<br/>
Open Container Initiative:<br/>
В 2015 году Docker и CoreOS запустили инициативу Open Container Initiative в партнерстве с The Linux Foundation, чтобы создать набор отраслевых стандартов в области открытых форматов контейнеров и среды выполнения.<br/>
