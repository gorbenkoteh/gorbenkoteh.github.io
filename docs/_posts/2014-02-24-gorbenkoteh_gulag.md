Репортаж из самого страшного музея Москвы: из музея ГУЛАГа. Текущая экспозиция посвящена трагедии маленького ингушского народа. "Испытания. 70 лет спустя" - так называется эта выставка - это живые свидетельства людей, переживших все ужасы сталинской депортации.

Блог из архива. Выставка была в далёком 2014 году. В каком виде этот музей сейчас - неизвестно.
